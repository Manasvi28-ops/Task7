# Task7
# Sales Summary Using SQLite and Python

This project connects to a small SQLite database, runs a SQL query to summarize product sales, and displays the results with a bar chart using Matplotlib.

# Tools Used
- Python (sqlite3)
- SQLite

# Files
- `sales_data.db`: Sample SQLite database with sales data.
- `sales_summary.py`: Main Python script to analyze sales.
- `sales_chart.png`: Output chart (generated when you run the script).
- `README.md`: Project overview.

#How to Run

1. Make sure you have Python installed with `pandas` and `matplotlib`:
   ```
   pip install pandas matplotlib
   ```

2. Run the script:
   ```
   python sales_summary.py
   ```
